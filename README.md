# betterNJUVPN

Windows 上访问南京大学部分校园网页的轻量工具。支持账号登录、短信验证、浏览器系统代理，以及可选的虚拟网卡分流；界面显示本地代理的实时速度和累计流量。

## 使用方法

1. 下载便携 ZIP 并完整解压，或运行安装包。启动 `betterNJUVPN.exe`。
2. 输入学号和密码，按提示完成短信验证。
3. 选择“系统代理”，打开下方开关。浏览器即可访问学校 Web 网关允许的网页；需要时可在界面调整端口和代理模式。
4. 虚拟网卡功能需要以管理员身份启动程序。选择“虚拟网卡”后打开同一个开关。程序接管设备流量；南大网页经本地代理，其他流量直连。
5. 首次使用 HTTPS 时，按需信任程序生成的 `data/ca.pem`。退出程序会恢复原有系统代理设置。

校内 IP 或非 Web 端口不会通过学校网关转发。界面底部的流量统计只计算经过本地代理的流量。

命令行程序 `betterNJUVPN-cli.exe` 随包提供。开发构建运行 `./build.ps1`，生成目录为 `dist/betterNJUVPN`；运行 `./release.ps1` 生成便携 ZIP 和安装包。
